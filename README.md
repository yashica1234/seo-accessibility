# SEO & Accessibility Webpage

A simple webpage optimized for **SEO and web accessibility** using HTML and CSS.

## Features

* Semantic HTML5 structure
* Proper heading hierarchy
* SEO-friendly title and meta description
* Accessible images using `alt` attributes
* Keyboard-friendly navigation
* Responsive viewport meta tag

## Technologies Used

* HTML5
* CSS3

## Concepts Practiced

### 1. Semantic HTML

Semantic tags clearly describe the purpose of different parts of a webpage.

Examples:
`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>`.

This helps browsers, search engines, and screen readers understand the page structure.

### 2. Heading Structure

Headings are arranged in a logical hierarchy:

```text
<h1>
  ↓
<h2>
  ↓
<h3>
```

`<h1>` represents the main topic, while `<h2>` and `<h3>` represent sections and subsections.

### 3. Meta Tags

Meta tags provide information about the webpage to browsers and search engines.

Used in this project:

* `charset` → Defines character encoding.
* `viewport` → Helps the page display correctly on different screen sizes.
* `description` → Gives a short description of the webpage.
* `author` → Specifies the page author.

### 4. SEO

**SEO (Search Engine Optimization)** helps search engines understand webpage content.

This project uses:

* Meaningful page title
* Meta description
* Proper headings
* Semantic HTML
* Descriptive content

### 5. Accessibility

Accessibility makes websites easier to use for different users, including people using screen readers or keyboards.

This project uses:

* `alt` text for images
* `lang="en"` for language identification
* Meaningful navigation links
* Logical heading structure
* Keyboard-friendly links
